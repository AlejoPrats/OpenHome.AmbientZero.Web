Sensors

The Sensors screen provides a centralized overview of all connected temperature sensors, displaying their real-time status, battery levels, and management actions.

Sensor Overview Table

Each row represents an individual sensor and displays the following details:

  • Sensor Name. The custom label assigned to the sensor or room.
  • Battery Remaining. Shows the estimated battery percentage (or the raw sensor value when enabled in the display options).
  • Last Reading. The date and timestamp of the most recent data transmission received from the sensor.
  • Temperature. The latest temperature value recorded by the sensor.
  • Signaling. Indicates whether the sensor is currently actively transmitting a signal (true or false).
  • Tendency. Shows whether the temperature is currently Rising, Descending, or has no recent trend available.

Sensor Display Options

Click the < Sensor Display Options button in the top-right corner to access additional view and management tools:

  • Show Raw Battery Readings. Switches the Battery Remaining column from percentages to raw numeric values. Use this option to read the exact raw values needed when configuring battery calibration thresholds in your settings.
  • Show Hidden Sensors. Temporarily reveals sensors that have been hidden from the main list. (Note: Hiding sensors is a local browser preference stored on your device and does not hide them for other users or devices.)
  • Force Merge. Allows you to manually combine any two sensors into one—even if they were not originally flagged as imported duplicates.

Row Actions

Use the action icons on the right side of each sensor row to manage individual devices:

  • Edit Name (Pencil icon). Rename the sensor to match its room or location.
  • Show Individual Chart (Bar chart icon). View a dedicated temperature history chart for this specific sensor. (Coming soon)
  • Hide Sensor (Crossed-out eye icon). Remove the sensor from your default view on this browser without deleting its data. You can bring it back anytime via Sensor Display Options > Show Hidden Sensors.
  • Configure Sensor (Gear icon). Open the configuration settings for that specific sensor.
  • Delete Sensor (Trash can icon). Permanently remove the sensor and its record from the system.
