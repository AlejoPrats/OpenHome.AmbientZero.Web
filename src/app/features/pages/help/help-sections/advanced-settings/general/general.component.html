Advanced Settings General

The Advanced Settings section gives administrators control over system updates, sensor battery calibration, and database backups. Because this screen modifies critical system behavior and sensitive data, access is password-protected by default.

Tip

Since this page contains multiple configuration sections, use the scroll-to-bottom arrow in the bottom-right corner to jump quickly to the Version and Backup controls.

Update Options

Configure how the system checks for and installs software updates:

  • Check For Updates. Automatically queries the remote server for newer versions of system modules.
  • Apply Updates Automatically. Installs available updates automatically without manual confirmation when enabled.

Battery Settings

Calibrate how raw battery voltage/ADC readings from your sensors translate into percentage values on the Sensors screen:

  • Max Battery Raw Reading. The raw sensor value that corresponds to 100% battery charge (e.g., 40944).
  • Min Battery Raw Reading. The raw sensor value that corresponds to 0% battery charge (e.g., 18320).

Tip

To find the exact numbers for your hardware, go to Sensors > Sensor Display Options and enable Show Raw Battery Readings.

Version & Module Updates

The Version table displays the current status of each system component (API, PCB, Web, and Sensor Code), comparing your Local Version against the Remote Version alongside the Last Updated timestamp.

  • Check For Updates. Manually triggers a check against the remote server to see if newer versions are available.
  • Updating a Module. When a remote version is higher than your local version, an upward arrow icon automatically appears in the Update column next to that module. Click it to install the update.
  • Enable / Disable Force Update. Toggles manual override mode, forcing the Update arrow icons to appear for all modules regardless of version numbers. Clicking a module's update icon in this mode opens a dialog where you can:
    • Update From Server. Pulls and installs the latest version directly from the remote server, bypassing version checks.
    • Update From File. Upload a local update package manually.

Caution

Force-updating bypasses standard version compatibility checks. Only use this option if you are troubleshooting or instructed to apply a specific build.

Backup Options (Import & Export Database)

Manage full database backups from the bottom of the screen:

  • Export Database
    • Click Export to open the export dialog.
    • Click Generate to build the backup file. A progress bar will display on screen while the export runs.
    • Once generation reaches 100%, the Download button becomes active—click it to save the backup file to your device. (If no backup has been generated yet, the Download button remains disabled.)
  • Import Database
    • Click Import to open the restore dialog.
    • Select or drag-and-drop a valid .sql backup file into the upload area.
    • Click Import to restore the database.

Important

Temporary Service Interruption During Backups & Restores: Exporting or importing the database is a resource-intensive operation. To prevent data corruption and free up system memory, the main API temporarily shuts down while a lightweight background maintenance service handles the database transfer and tracks progress.
  • While the progress bar is running, the application will not be operational and incoming sensor readings will not be recorded.
  • Refreshing the page will not cancel an active export or import—the process continues safely in the background until it finishes and automatically restarts the main API.
