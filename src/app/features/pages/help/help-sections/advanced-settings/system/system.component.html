Advanced Settings System

The System tab monitors the real-time hardware health and resource usage of your device. By default, each status card appears in a compact collapsed view showing a color-coded health indicator and summary message.

  • Expand / Collapse Details (Chevron arrow icon). Click the arrow button on the right side of any card to expand or hide detailed hardware metrics.
  • Info Tooltip ( i icon). Hover over or click the info icon in the top-right corner of each card to view threshold explanations and guidance for that metric.

Ram Status

Displays current system memory health (such as Nominal):

  • Clean Cache. Clears non-essential system page caches to reclaim memory without interrupting active services.
  • Force Free Memory. Aggressively releases cached and buffered memory when available RAM runs low.
  • Ram Details (Expanded view). Shows exact Available and Free memory in MiB.

Swap Status

Monitors virtual swap memory usage (such as Some swap used but safe):

  • Swap Details (Expanded view). Shows the amount of swap space currently Used in MiB.

Cpu Status

Tracks processor thermal health (such as Warm but Safe):

  • Cpu Details (Expanded view). Shows the current processor Temperature reading.
