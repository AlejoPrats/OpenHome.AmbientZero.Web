Advanced Settings Security

The Security tab lets you manage administrator and SSH credentials and control which areas of the application require password authentication.

System Passwords

  • Admin Password. Click Change Admin Password to update the master administrator password configured during initial setup.
  • SSH Password. Displays the system's SSH login password for remote terminal access. This password is uniquely and randomly generated during each installation.
    • Show / Hide (Eye icon). Toggle visibility to reveal or mask the SSH password on screen.
    • Copy (Clipboard icon). Copy the SSH password directly to your clipboard.

Application Security

The Application Protection dropdown sets the global access restriction level across both the user interface and the backend API:

  • Open. Allows unrestricted access to general views (such as charts and sensor overviews) without logging in. Advanced Settings remains password-protected at all times.
  • Settings (Default). General monitoring screens remain accessible, while configuration pages (such as Basic Settings and Advanced Settings) require authentication.
  • All. Locks the entire application behind a login prompt, requiring authentication to view any screen or access API endpoints.
