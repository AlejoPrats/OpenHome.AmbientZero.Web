Advanced Settings Network

The Network tab allows you to configure the built-in wireless Access Point (AP) that your sensors and devices connect to.

Access Point Settings

  • Name. Set the Wi-Fi network name (SSID) broadcast by the Access Point (for example, AmbientZero). Click the × inside the field to clear the current name.
  • Authentication Method. Choose the security mode for the Access Point:
    • Open. Allows devices to connect without a password. When selected, the Password field is disabled.
    • Password Protected (WPA2-TKIP). Secures the Access Point with a password and enables the Password input field.
  • Password. Enter the Wi-Fi password required for devices to join the network. As you type, a live password strength indicator evaluates the password's length and entropy, rating it as Weak, Normal, or Strong so you can choose a secure passphrase.
  • Channel Selection & Noise Scan (Coming soon). Allows you to select a Wi-Fi channel (1 through 11) and scan surrounding wireless traffic to pick the channel with the least interference.

Saving Changes

• Save. Click the Save button in the bottom-right corner to apply your new Access Point configuration. Important: Changing the Access Point Name, Password, or Authentication Method will disconnect currently connected devices and sensors until they are updated with the new network credentials.
